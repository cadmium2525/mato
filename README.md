# 的、逃走中。（TARGET ESCAPE）

> あなたは的です。襲いかかってくる小便から逃げてください。

男子小便器の内側に貼られた「的」になって、次々に現れる利用者の尿の着弾をかわし、何人分を生き延びられるかを競う 3D ブラウザゲームです。
Three.js + TypeScript + Vite の完全クライアントサイド構成で、GitHub Pages の無料枠で配信できます（サーバー・API・DB・認証なし）。

- 企画: [`GAME_DESIGN.md`](./GAME_DESIGN.md)
- 実装指示: [`CLAUDE_CODE_INSTRUCTIONS.md`](./CLAUDE_CODE_INSTRUCTIONS.md)

## 遊び方

| 操作 | キー |
|---|---|
| 移動 | WASD / 矢印キー |
| ポーズ / 再開 | Esc（P でも可） |
| スタート / 演出スキップ / リトライ | Enter / Space |
| リトライ（リザルト画面） | R |
| タイトルへ（リザルト・ポーズ画面） | T |

### スマホ・タブレット（タッチ操作）

| 操作 | タッチ |
|---|---|
| 移動 | 画面のどこでもドラッグ（触った位置に仮想スティックが出る） |
| ポーズ | 画面の Ⅱ ボタン（縦持ちは上中央、横持ちは左下） |
| 演出スキップ | 画面をタップ |
| スタート / リトライなど | ボタンをタップ |

- スティックはアナログ入力で、指を約56px動かすと最高速（キーボードと同じ速度。それ以上速くはならない）。
- 大きく動かしたあとでも、少し逆へ戻すだけで切り返せる（基点が指に追従する）。
- 縦持ち・横持ちどちらでも遊べる。縦持ちは情報を上に集めて下半分を指用に空け、横持ちは便器の上端が隠れないよう少し引いた画にしている。
- ピンチ拡大・ダブルタップ拡大・スクロール・長押しメニューは無効化。ノッチ/ホームバーのセーフエリアに対応。
- バックグラウンドに回す・通知などでフォーカスが外れると自動でポーズ。
- タッチ端末では描画解像度の上限を devicePixelRatio 1.5 に抑える（発熱・電池対策）。重い場合は `?low` を付ける。
- マウスでも画面ドラッグでスティック操作が可能。

- 黄色いリングは**相手の照準**。点滅中は予備動作（まだ発射しない）や攻撃の切り替え、常時表示は発射中です。2WAY/3WAY ではリングが尿流の本数だけ出ます。
- オレンジのリングは**着弾予告**（ショットガンの粒・マッチョの跳ね返り）。縮んで判定の大きさになった瞬間に着弾します。
- 尿は発射時点の照準に向かって飛び、飛行時間（約0.3秒）後に着弾します。**発射後に的を追尾しません**。
- 1人分の排尿が終わるまで生き残ると「◯人抜き」。一度でも命中するとゲームオーバー。
- 画面右下の「順番待ち」と、カメラが映す行列は実際の登場順と一致しています。
- ウィンドウのフォーカスが外れると自動でポーズします。

### URL パラメータ

| パラメータ | 内容 |
|---|---|
| `?seed=123` | 乱数シード固定（同じ行列順・照準の揺れを再現） |
| `?low` | 低画質モード（影なし・アンチエイリアスなし・解像度1倍） |
| `?touch` | タッチ用UI表示を強制（PCでの確認用。通常は `pointer: coarse` で自動判定） |
| `?debug` | `window.__MATO__.state()` で内部状態を参照可能（E2E確認用） |
| `?debug&god` | デバッグ用の無敵モード（被弾を無視） |
| `?debug&attack=shotgun` | デバッグ用に攻撃の種類を固定（single / twoWay / threeWay / shotgun / combo） |

## ローカル開発

Node.js 22 以上を推奨（Vite 8 の要件: `^20.19 || >=22.12`）。

```bash
npm install
npm run dev        # http://localhost:5173/ で起動
npm test           # ユニットテスト（Vitest）
npm run typecheck  # 型チェック
npm run build      # 型チェック + 本番ビルド（dist/）
npm run preview    # ビルド結果の確認
```

サブパス配信を手元で確認する場合:

```bash
VITE_BASE_PATH=/mato/ npm run build
```

## GitHub Pages への公開

`.github/workflows/deploy.yml` が `main` への push と手動実行（workflow_dispatch）で
`npm ci → npm test → npm run build → Pages Artifact アップロード → デプロイ` を行います。

**リポジトリ側で必要な手動設定（1回だけ）**

1. GitHub のリポジトリ画面で **Settings → Pages** を開く
2. **Build and deployment → Source** を **GitHub Actions** にする
3. `main` に push するか、Actions タブから「Deploy to GitHub Pages」を手動実行する

公開URLの想定: `https://cadmium2525.github.io/mato/`
（Pages を有効化してワークフローが成功するまでは公開されていません）

### base パスの決め方（`vite.config.ts`）

1. `VITE_BASE_PATH` があればそれを使う
2. GitHub Actions 上では `GITHUB_REPOSITORY` からリポジトリ名を取り `/REPO/` にする
   （`USER.github.io` リポジトリ＝ユーザー/組織ページの場合はルート `/`）
3. それ以外（ローカル）は `/`

### Phase 2: Full Core — 完了

- **4キャラすべて実装**（行列に4種が並び、表示順＝登場順）
  - サラリーマン: 高精度で安定した追尾
  - 酔っ払い: 時間連続の左右揺れ＋大きな反応遅れ（フレームごとの乱数ワープなし）
  - おじいちゃん: 断続発射。再開の直前に照準リングが点滅して予兆を出す
  - マッチョ: 大きな着弾。着弾20回に1回、着弾点の少し下へ**跳ね返り**。一次着弾の瞬間に予告リングが出て、0.38秒後に二次着弾
- **攻撃パターン**（すべて同じ `Impact` 配列で表現し、描画はそれを可視化するだけ）
  - 2WAY: 照準の左右に2本。内側の空き11cm（的の判定直径の約2倍）を着弾半径によらず確保。照準に追われている間は隙間に入っていれば安全
  - 3WAY: 中央＋左右下の「Λ」字。照準と同じ高さを横へ逃げる道は常に空いている
  - ショットガン: 照準を要とした扇（110°）に5〜7粒。**着弾地点を0.45秒前に予告**してから発射し、飛行時間を足して約0.75秒の猶予。粒の位置は予告の時点で確定（シード付き乱数）
  - コンボ: 上記4種を1.6〜2.4秒の区間で順に使い、区間の間に必ず0.55秒の休止（照準点滅で予告）。前区間の着弾が終わってから次区間が着弾する
  - 2WAY/3WAY の間は照準が鈍る（追尾速度×0.85 / ×0.7）
- **人数解禁テーブル**: 1〜3 single / 4〜 2WAY / 8〜 3WAY / 13〜 ショットガン / 18〜 コンボ。解禁された人数で、その攻撃が**必ず1回出る**（「新攻撃」表示）。以降は最新の攻撃40%・既存の攻撃を均等に混ぜる。HUDに現在の攻撃名を表示
- ニアミス・回避スコア・自己ベスト・ポーズ（Phase 1 で実装済み）
- **回避経路の検証**: 見えている情報だけで避ける計画型ボットで、全キャラ×全攻撃を解禁人数の難易度で自動テスト（下記）

## 技術上の決定事項（仮仕様）

- **表面モデル**: 内壁は鉛直な楕円柱の一部（横半径0.20m・奥行0.24m・左右±62°・高さ0.46m）。`u` は角度ではなく**弧長の割合**に対応させたので、`toMetricUV(u,v) = (u·幅, v·高さ)` が曲面上の実距離と一致する（局所補正をテーブルで内包）。
- **単位**: ロジックはメートル・秒。判定はメトリック座標の円同士。
- **固定ステップ**: 判定は 1/120 秒の固定ステップ、フレーム間隔の上限は 0.1 秒。
- **尿のモデル**: 発射中は 1/60 秒ごとに Impact を生成（判定時間 0.09 秒）。尿流は 0.6 秒ごとに別の攻撃IDに区切り、ニアミスはその単位で1回。
- **公平性の自動検証**: テスト用の計画型ボットは、飛行中の尿粒・予告マーカー・照準リングだけを見て、9方向について0.6秒先までの進路を試算し、最初の衝突が最も遅い方向を選ぶ（反応は1/30秒ごと）。参考値（各40シード）: ほぼ全組み合わせで95〜100%、最難関は「3WAY×酔っ払い」で約75%（揺れを読む必要があるため。人間はリズムで読める想定）。
- **公平性**: 照準の追尾速度は的の速度（横幅/0.7秒 ≒ 0.64m/s）より必ず遅い（難易度倍率込み、テストで保証）。照準は的と反対側から出現し、予備動作 0.9〜1.1 秒は発射しない。
- **判定半径**: 的の見た目半径 3.2cm × 0.85。
- **カメラ**: プレイ中は便器正面に固定（画面右 = u+、上 = v+）。プレイ中は利用者の体がカメラと重なるため非表示にし、入場・退場はカメラを引いた画で見せる。
- **スコア**: 生存1秒10点、ニアミス100点、1.5秒以内の連続3回ごとに+300点、1人完遂+500点。ベストは人数→スコア→生存時間で比較。
- **シード**: 毎ゲームランダム（`?seed=` で固定）。待機列・照準の揺れ位相を再現できる。
- **素材**: 外部画像・フォント・音源なし。人物・便器はプリミティブと自前の曲面メッシュ、タイルと的はCanvasで生成。
